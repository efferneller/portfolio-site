Контекст

Большой фестиваль спорта — это главное ежегодное масштабное корпоративное спортивное событие компании, объединяющее сотрудников из десятков дочерних обществ и регионов присутствия. Цель мероприятия является популяризация здорового образа жизни, развитие корпоративного спорта, укрепление командного духа и горизонтальных связей между сотрудниками разных предприятий компании.

Задача

Подготовить материалы для анонсов мероприятий, освещения соревнований и публикации результатов.

Ключевые решения

  • Оформление баннеров мероприятий;
  • Дизайн карточек с результатами;
  • Подготовка материалов для официального новостного канала команды.
